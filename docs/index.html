功能介绍

面向 Bilibili 的 Edge / Chromium userscript。优化首页、搜索页和播放页的网络调度与 CDN 使用，并在播放器右键菜单中提供下载工作台。

01

首页信息流

首屏更快，下滑更稳。

  • 页面加载初期预连接常用接口和图片域名
  • 提升推荐接口优先级，可见封面优先加载，视口下方预加载 4–10 行
  • 默认隐藏广告楼层，不影响普通视频卡片
  • 停止下滑约 3 秒后自动加载后续内容
  • 修正网格错位、抖动和频闪
02

CDN 优选

根据地域和实测结果选择图片与播放节点。

  • 区分国内和境外出口，地域未确认时保持原始地址
  • 图片节点实测后短期缓存，连续失败才切换
  • 播放地址替换覆盖播放页、首页和搜索页的悬停预览
  • 不伪造签名，不改清晰度和播放器交互
测速中 示意动画，非实时数据
    03

    下载工作台

    在播放器右键菜单中打开，默认选中当前视频和当前分 P。

    • 可合并为 MP4，直通封装不重新编码；也可分轨下载或仅导出音频
    • 统一的视频列表，支持分 P、合集和番剧多季度批量选择
    • 清晰度和编码分开选择，无法匹配时自动降级
    • 显示文件大小、下载与转码进度、总速度和预计时间
    • 文件名格式统一，音频自动写入元数据
    04

    收藏夹修复

    为“已失效视频”找回能确认的信息。

    • 恢复标题、封面、简介、UP 主、时长和分 P
    • 补回 UP 主设为“仅自己可见”的隐藏收藏
    • 悬停失效封面可查看完整资料面板
    • 卡片菜单可复制信息、查看封面和清除缓存
    05

    播放交互

    按自己的习惯打开和切换视频。

    • 视频卡片可用抽屉、新标签页或当前页打开
    • 抽屉支持网页全屏
    • “回程”胶囊记录导航，返回时可恢复播放进度
    • 正式播放时防止屏幕休眠
    06

    设置面板

    点击首页右下角的齿轮打开，每个模块都可以单独开关。

    • CDN 优选、主题同步、评论信息、防睡眠
    • 免登录、回程、首页加载、收藏夹修复
    • 下载工作台的进度显示和刷新间隔

    安装

    1. 安装 Tampermonkey 或其他兼容的 userscript 管理器。
    2. 点击下方按钮，在管理器中确认安装。
      安装脚本
    3. 打开 Bilibili 首页，右下角出现 BiliKit 齿轮按钮，说明脚本已经生效。

    如果装过旧版 BiliKit Core，请先停用它，避免两个脚本同时修改页面。
