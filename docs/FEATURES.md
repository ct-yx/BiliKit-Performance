# BiliKit Performance 功能介绍

当前版本：**0.6.48**

BiliKit Performance 是面向 Edge / Chromium 的 Bilibili userscript，主要提供首页与 CDN 优化、播放交互增强、播放器下载工作台，以及收藏夹失效视频修复。详细实现以当前发布脚本为准：[bilikit-performance.user.js](../bilikit-performance.user.js)。

## 首页、搜索和 CDN

- 首页在页面早期预连接常用接口和图片域名，调整推荐、播放和图片资源的请求优先级。
- 预加载首屏附近的封面，并按设置在停止滚动后尝试触发 B 站原生首页加载；不改写视频悬停预览。
- 隐藏首页信息流广告楼层，修复部分信息流网格间距造成的错位和抖动。
- 搜索页只处理连接和已知接口 URL 问题，搜索结果与悬停预览继续使用 B 站原生逻辑。
- 根据网络地区和实际探测结果选择图片、播放资源的 CDN；对带签名的代理地址保留安全边界，不伪造 MCDN 签名。

## 播放交互

- 视频卡片支持抽屉、新标签页或当前页打开。
- 播放页提供“回程”能力，可返回上一个视频并按设置恢复播放进度。
- 正式播放时可申请 Screen Wake Lock，减少设备自动休眠；悬停预览不会申请唤醒锁。
- “稍后再看”“不感兴趣”和“更多”等原生操作继续交给 B 站处理。

## 播放器下载工作台

工作台从播放器右键菜单打开，使用当前页面的官方播放信息，不调用第三方下载接口。设置入口位于 B 站首页右下角的 BiliKit 齿轮，下载显示项和刷新参数可在“下载工作台”模块中调整。

### 普通视频模式

普通视频模式使用一个统一的视频列表，同时处理同一 BV 的分 P 和不同 BV 的合集：

- 当前 BV 的分 P 使用 `P01`、`P02` 标识。
- 合集视频使用 `C01`、`C02` 作为父项；父项可以一次选择该 BV 的全部 P，子项使用 `C01_P01`、`C01_P02` 等标识。
- 合集视频与其内部 P、当前 BV 的普通分 P 可以同时加入同一批任务；推荐列表中无关的其他 BV 不会被加入。
- 默认只勾选当前视频，支持“全选”“取消全选”和逐项选择。每个实际任务都独立使用自己的 BVID/AV、CID 和播放接口响应。

支持三种操作：

1. 合并视频和音频为 MP4；
2. 分别下载视频轨和音频轨；
3. 仅下载音频轨。

清晰度和编码以当前选择为目标，其他视频按相同清晰度同编码、相同清晰度其他编码、较低清晰度、最低可用清晰度的顺序匹配。合并是 MP4 直通重封装，不重新编码；资源不可用、过期、付费或受保护时不会绕过限制。

### 番剧模式

番剧模式与普通视频模式独立，识别 B 站 `/bangumi/play/` 页面，并读取官方 PGC 季度和正片集目录：

- 单季度按 `E01`、`E02` 展示；多季度按 `S01E01`、`S02E01` 展示，并以季度父项支持整季选择。
- 默认只勾选当前集，也支持季度全选、列表全选、取消全选和单集选择。
- 每集独立使用自己的 `season_id`、`ep_id`、BVID/AID 和 CID 获取播放轨道，不混用普通视频模式的目录或缓存。
- 番剧远程目录和播放请求最多并发 2 个；轨道取得后，本地 MP4 合并仍使用独立的合并调度。

### 下载任务和合并调度

- 分轨任务在确认轨道后直接交给浏览器下载管理器，不进入本地合并任务池。
- 合并任务最多同时运行 4 个，并根据 CPU、可用内存、视频时长、码率和清晰度估算容量；超出预算或超长任务会排队。
- 单个任务失败、取消或重试不会阻断同批次其他任务；切换视频、分 P、合集或番剧页面时会清理旧任务和旧轨道。
- 文件名包含主标题、BV、列表序号、实际清晰度、编码、音频码率和容器扩展名，例如：

  `标题_BVxxxx_C02_P02_1080P_AVC_AAC_video_audio.mp4`

### 进度与估算

- 每个任务可显示估算文件大小、下载进度、合并进度和综合进度。
- 全局摘要显示总下载速度、按媒体大小加权的综合进度、预计下载时间和预计总计时间。
- 不单独显示全局预计转码时间；合并耗时样本只用于预计总计时间模型。
- 默认约每 500 毫秒刷新，可在设置中调整为 250–2000 毫秒；合并耗时模型保留最近 3 条达到阈值的样本。

## 收藏夹修复

在公开收藏夹页面中，脚本只处理仍显示“已失效视频”的目标卡片：

- 优先使用 B 站官方收藏夹公开元数据，再按 AV 号补充可确认的标题、封面、简介、UP 主、分区、时间、统计和分 P 信息。
- 标题和封面独立恢复；失败时进入明确终态，不永久保留“正在加载数据”。完全失败时使用 `查不到标题（AV号）【鼠标悬停查看简介】` 作为页面显示兜底。
- 仍使用失效占位封面的目标卡片支持悬停或键盘聚焦资料面板，面板固定在视口内并内部滚动，不改变卡片尺寸，也不拦截 B 站原生跳转。
- 正常收藏卡片不会被改写、插入工具菜单或增加资料面板；隐藏条目只有在官方公开接口明确确认时才按原顺序补回。
- 本地缓存只保存公开元数据和有限时间的命中状态，不保存 Cookie、签名 URL、媒体地址或第三方脚本内容。

## 设置与限制

设置面板按模块控制首页加载、CDN、主题、回程、防睡眠、收藏夹修复和下载工作台。下载工作台可分别控制摘要、总速度、综合进度、文件大小、任务阶段进度、刷新间隔和合并估算样本阈值。

脚本不绕过登录、会员、付费、DRM、地区限制或其他访问控制；官方接口或媒体资源不可访问时，会保留失败提示，不伪造数据。下载功能只针对当前页面识别出的同 BV 分 P、合集条目或番剧正片，不处理推荐列表中与当前视频无关的项目。
